# B4 V2 测试记录

按用户选择使用当前V2独立最终包的B4Solver，不覆盖为G52-T160旧检查点。源码仍由B4/source_manifest.json核验，新增适配在tools目录，不改变V2求解策略。

每次先在模拟器选择问题4及对应模式并启动，再执行一条命令。每条仅运行一局，不会自动连跑，也不会打开文件夹。队号默认202623001400。

演练（重复手动执行5轮）：

```powershell
python -B -X utf8 tools/test_evidence/run_b4_test.py --mode rehearsal --ready
```

正式（准备好后重复手动执行3轮）：

```powershell
python -B -X utf8 tools/test_evidence/run_b4_test.py --mode formal --ready
```

结束后在窗口粘贴本局案例编码并回车。脚本保存编号、动作、结果、源码哈希和轨迹，并追加累计表。同一日志重复导出不重复计数。下次运行前关闭Excel总表；手填总表案例编码也会保留。

- 演练总表：B4/results/v2_rehearsal/summary/table.csv
- 正式总表：B4/results/v2_formal/summary/table.csv
- 各局：对应类型下run-时间戳；simulator_logs自动创建，请保存原名加密日志及截图。evidence-时间戳中为SVG和动作明细。

只补录编码或重试导出（不会连接模拟器）：

```powershell
python -B -X utf8 tools/test_evidence/run_b4_test.py --mode rehearsal --record-only "本局完整目录"
```

正式补录改为--mode formal。也可增加--case-code "案例编码"跳过交互。异常测试同样保留已确认动作并计入本地次数，不自动重跑；未正常退出或成本不一致时完整平均时间留空。仅有未确认enter时不能生成完整轨迹，日志会保留。5/3上限是此适配器本地运行记录，不代表模拟器官方剩余次数。缺失总源数不计算清除率，程序耗时默认接口时间戳重建值。
