# B2：第二检测点鲁棒选择

状态：**核心模型、正式 Python 实现、回归测试与离线合成验证均已完成**。本目录只解决 B 题问题2；没有运行正式模拟器，也不宣称得到连续全平面的全局最优点。

## 已完成内容

- 根据首次正常示向度构造物理可行源集合 `K`。
- 给出保证再次接收的隐式区域 `C_safe`，以及可解析计算的安全子域 `C_cert`。
- 在 `C_cert` 内进一步构造保证获得正常第二示向度、且 B1 纯角度交会区域有界的实现域 `C0_sub`。
- 将“源位置 + 第二次 ±1° 测向误差”压缩为一个连续的第二示向度区间，在该区间内自适应细分最坏情况。
- 主指标：最坏情况下的 B1 定位区域直径；辅助指标：最坏最小覆盖圆半径；移动距离仅在数值同分时比较。
- 对领先候选使用 65 位高精度复核，并用独立密集角度扫描检查自适应包络。
- 29 项 B2 测试和 27 项 B1 回归测试均可在 GitHub 仓库布局下一键运行。

## 当前冻结的人工案例

中央案例 `s1=(0,0), θ1=0°` 的有限候选搜索推荐局部第二点约为 `(775,-625) m`，移动约 `995.615 m`；保守外包络 `H` 上的最坏定位直径约为 `136.126–137.050 m`，最坏最小覆盖圆半径约为 `68.063–68.525 m`。这些数字只用于验证算法行为，**不是题目给定实例的最终答案，也不是连续全局最优证明**。

## 结果解释边界

- `C_safe` 是保证接收的数学定义，完整边界未显式求出。
- 实现搜索的是经过证明的保守子域 `C0_sub`，因此结果可能偏保守。
- `H` 是物理可行源集合 `K` 的凸外包络，故其最坏上界可安全用于 `K`，但其采样下界不能自动当成 `K` 的下界；程序会尽可能恢复物理见证。
- 浮点包络 + 65 位复核是数值验证，不是严格外向舍入的区间算术证书。
- MEC 半径用于解释“后续 20 m 清除”的几何意义，不替代题目2的主定位精度指标。
