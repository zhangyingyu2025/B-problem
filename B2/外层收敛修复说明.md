# B2 外层候选点收敛修复

本增量只修复 B2 的 **第二检测点外层数值搜索/收敛判定**，不修改 B1，也不改变 B2 的物理模型、接收保障集合或固定候选点的连续二次读数 minimax 计算。

## 修复的问题

旧版默认搜索为 100 m 粗网格，并只在每侧少量 leader 周围做 50 m、25 m 局部细化。固定候选点后的内层最坏读数计算已经较稳定，但外层候选网格仍可能过粗，因此网格加密后可能出现：

- 推荐点明显移动；
- 最坏直径显著下降；
- 旧程序仍直接输出 `completed_with_numerical_bounds`，没有把“内层稳定、外层未收敛”分开报告。

## 新搜索

默认采用多起点分层网格：

```text
50 m -> 25 m -> 12.5 m -> 6.25 m
```

每一层：

1. 保留左右两个候选叶瓣，而不是只围绕一个冠军；
2. 每侧保留多个领先候选；
3. 同时保留“采样下界仍与当前冠军上界重叠”的竞争候选；
4. 在这些候选附近做下一层 5x5 局部网格；
5. 记录每层最佳目标值、最佳点位移和候选数。

默认总候选预算提高到 2500，但通常远低于预算。

## 内外层误差分离

新输出增加：

```text
outer_convergence
inner_convergence
```

`inner_convergence`：固定最终推荐点，将最坏二次读数的区间预算从默认 768 再提升到 1536，检查最坏直径上界是否稳定。

`outer_convergence`：检查最后两层候选网格的：

- 最坏直径变化；
- 推荐点位移；
- 是否触发候选预算截断。

若任一层未稳定，顶层 `status` 返回：

```text
needs_refinement
```

而不是把未收敛的网格结果伪装为最终数值。

## 修复后复核结果

### 中央人工案例 `(0,0; 0°)`

旧冻结结果：

```text
S2 = (775, -625) m
worst D upper = 137.049720 m
```

新默认收敛搜索：

```text
S2 = (793.75, -606.25) m
worst D = [135.258709, 136.111151] m
outer = stable
inner = stable
```

旧 -> 新最坏直径上界下降约 **0.685%**。

最后 `12.5 -> 6.25 m` 两层：

```text
136.421314 -> 136.111151 m
相对变化 0.227%
推荐点移动 8.839 m
```

固定最终推荐点，内层 `768 -> 1536` 区间复核的最坏直径上界变化为 **0 m**。

### 边缘人工案例 `(1500,0; 0°)`

旧冻结结果：

```text
S2 = (225, -225) m
worst D upper = 17.635133 m
```

新默认收敛搜索：

```text
S2 = (225, -175) m
worst D = [16.348936, 17.326218] m
outer = stable
inner = stable
```

旧 -> 新最坏直径上界下降约 **1.752%**。

该案例在 `50 -> 25 m` 时目标仍变化约 6.39%，因此旧粗网格确实不能冻结；但 `25 -> 12.5 -> 6.25 m` 后推荐点和目标均稳定。

### 跨 0° 案例

局部几何与中央案例一致，新结果同样收敛到：

```text
(793.75, -606.25) m
D upper = 136.111151 m
outer = stable
inner = stable
```

## 仍然没有声称什么

本修复解决的是 **“候选点网格明显未收敛却被直接冻结”** 的问题，并使内层和外层收敛状态可审计。

它仍不等价于严格证明：

```text
连续 C0 上的全局数学最优点已经被证明找到
```

因此论文中仍应称“数值近优/收敛推荐点”，而不是严格连续全局最优。
