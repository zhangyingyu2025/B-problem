# G41-JCR Phase A：DEV20 未晋级，保留 G40

按任务书在 fresh DEV20 停止。G41 全清且未触发几何不变量失败，但加权时间恶化3.038%，移动增加4.144%。没有启动fresh50、第二批fresh50、专项批次、Phase B、HOLDOUT或官方模拟器。这个结果否定的是本轮保守上界实现的性能，不是宣称所有联合路由方法都无效。

Stage0：58项原有B4测试通过；G40 smoke64240980–64240999，20/20全清、258源、478.185693秒/源。这个独立小批与提供的100场G40报告样本不同，不要求均值相等。

最终新增17项G41测试（数学、路由、执行），全套B4共75项通过。关闭JCR后在六类全新endpoint场景与G40逐动作/指标严格一致；开启后通过只持响应的ReplayPort重放。AST检查两个新模块不读case、seed或源真值。异常覆盖序列用故障注入验证：先记invariant，再调用有限fallback；不把恢复成功当无失败。

## 失败归因

1. **瓶颈仍是移动。** 平均每场移动成本增加181.450s，measure增加0.750s，switch减少0.750s，clear失败增加2.100s，总增加183.550s。没有专门新增pair probe（0次），因此本轮退化不是“额外测量泛滥”；访问顺序与源任务穿插的变化才是主因。
2. **最坏上界太松，无法衡量边际价值。** active成本使用原G40全部剩余fan加最多108点fallback的粗保守完成上界，常达数十万等效米；pair上界只有数千米。117次新延期决定累计预测上界差约1.092亿等效米，而实际配对路程总计反而增加18.145km。该预测含重规划后的重复决策，绝不是可相加的真实节省，更不是通过率收益。
3. **执行收益远少于规划选择。** 共875次重规划、165743次J评估、916个有向pair候选，选择计数458次（含重规划重复）；实际有限resolver完成8次，共21次clear尝试。fan仅少4步，抵不过改变证书访问及清源穿插造成的路程。
4. **N=16提前发现被拖晚。** 三场certificate访问数从G40的16/15/14变成G41的21/17/21，多走14站。实际发现16源后确实取消证书；取消pending pair计数为0，说明退化发生在发现第16源之前，而非发现后仍偷用免费站点。
5. **求解时间不是瓶颈。** planner平均0.177s/场，最大0.401s，未触发30s保护。累积重规划路线长度差-528.394m不等于真实路程变化；其起点/剩余任务每轮不同，不能作为实现节省证据。

## 数学实现与限制

`jcr_cost.py`只读G40数学函数。对safe点q，使用rho≤1000和完整wedge side；普通no_signal不会进入新的backside逻辑。第二direction预测采用更保守的全sector夹角下界：H=1500sinα，η=asin(max(0,|q_y|-H)/rho)，γmin=max(0,η−α)。这是由任一源的法向间距下界与距离上界推得；不使用未知的真实示向角。当γmin不足3°时拒绝pair。

两strip的窄半宽w1=(rho+3e-6)sinα+2e-5，宽半宽w0=1500sinα+2e-5，轴向半长S=(w0+w1cosγmin)/sinγmin。采用G40相同半径19.9995的圆，n=ceil(S/sqrt(Rclear²−w1²))。每个矩形单元最远角到圆心小于20m，因此覆盖整个平行四边形。未知direction分支的闭合扫清路程上界为2rho+4S；clear代价15(n−1)+25。已有G40条件下，safe扇形最大距离确由原点和两个远端点控制；对safe q，其局部前向坐标为正，弧上的距离最大值位于端点。

双负分支复用严格chord_radial_upper，加向外数值裕量后在[0,R]×[−Rsinα,Rsinα]外包矩形上做有限中心射线清除，横向半宽小于19.9995才能接受。三个分支费用取最大；收费含局部扫清后返回当前站点的路程。实际可直接接向下一站，三角不等式保证不大于先返回的预算。Phase A没有零移动route-clear，两个相关统计为0。

active上界依赖保留的G40 fan_limit=8、至多一次center probe、strip≤20点及full-wedge fallback≤108点；源在首次anchor的1500m内，接收anchor距源≤1500m，SPF保持距离，所有后续相关位置可被3500m粗球包住。逐动作7000m的粗界和有限动作计数给出完成上界。这很保守，实验已证明它不适合直接解释为节省预测。

J=L+sum(min(Cactive,Cpair))是当前已发现源、条件证书路线上的上界代理目标。它不包含未知源未来信息价值，也不宣称是交织执行后整个任务的紧上界。路线搜索固定4轮、4000次评估上限，邻域2-opt/relocate/swap，正常执行确定性；仅异常超出30s规划预算时停用JCR回G40。

成本审计曾发现遗漏probe之后恢复频道的最多5m费用。原attempt0留存并标无效，不用于晋级；修正增加两端切换计费测试后，使用同20场重跑，未换seed或阈值。修正版与旧版20/20实际动作序列相同，说明记账修正没有产生选场收益。所有性能结论均来自修正版v1。
