## 参数和信息边界

| 项目 | 来源事实 | 本实现处理 |
|---|---|---|
| 坐标 | 米；东为 x 正向，北为 y 正向 | 有限数值，不使用目标圆域截断 |
| 示向度 | 从东逆时针，范围 `[0,360)` | 校验单位和范围，使用向量叉积处理跨零 |
| 测向误差 | 全局在 ±1° 内 | 误差半角默认1°；无概率分布假设 |
| 同点重复测量 | 误差不因重复检测改变 | 完全重复去重，不按独立样本降噪 |
| 接口读数 | `svd_deg` 保留两位小数 | 理论误差界不自动改为1.005°；若后续接入需另审计舍入语义 |
| 正常测向 | `direction` 才有角度 | 当前接口要求上游只提供有效角度 |
| 无信号/过近 | `no_signal`、`near` 没有角度 | 拒绝伪装成角度观测 |
| 目标分布圆域 | 半径1800米 | 属于全题先验，不加入本轮多边形定义 |
| 接收半径 | 每源1000–1500米之间，具体未知 | 不把未知半径当作精确测距 |

## 输入质量规则

真实观测尚未提供，当前示例都明确标记 `synthetic`。API 校验有限数值、缺字段、额外字段、角度范围；CLI 额外拒绝重复 JSON 键和非有限常量。同站冲突读数保留，让可行性求解暴露冲突；不擅自删除异常观测。

需要注意：闭楔形模型包含检测点本身，互不相容的同站角度可能仅交于该点。这是纯闭半平面模型的退化结果，不等价于实际设备能在干扰源处获得正常角度；5米过近约束未被并入此模型。
